QUÉ HAGO

¿Qué puedo aportar a tu equipo?

Del modelo de datos a la interfaz, con la arquitectura pensada para que el producto pueda crecer sin romperse.

Arquitectura

Clean Architecture, hexagonal y DDD cuando el producto lo pide: bounded contexts, fronteras entre módulos que se verifican solas y decisiones documentadas.

Backend

APIs con NestJS o Fastify, Prisma o Drizzle, colas con BullMQ, emails, facturación y eventos de dominio. Lógica de negocio donde tiene que estar.

Frontend

React con Next.js o Vite, estado bien organizado (Zustand, TanStack Query y Router), interfaces responsive y PDFs generados en cliente.

Datos multi-tenant

Modelos de datos alineados con el dominio y aislamiento entre clientes con Row-Level Security de PostgreSQL.

Testing

Unitarios con Vitest y Jest, y end-to-end contra una base de datos aislada. Hooks de calidad antes de cada commit.

Integraciones

Calendarios con webhooks, pagos con Stripe, emails con Amazon SES e impresoras de tickets ESC/POS.
